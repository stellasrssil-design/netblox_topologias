# NetBlox 3D: Arquiteto de Topologias

Jogo 3D interativo em JavaScript (Three.js) inspirado no estilo Roblox e baseado nos diagramas de topologias de rede do Cisco Packet Tracer.

## Estrutura do Projeto
- `index.html`: Interface principal, HUD e canvas 3D.
- `css/style.css`: Estilização da HUD e controles responsivos.
- `js/topologies.js`: Definição dos nós e enlaces das 7 topologias (Ponto a Ponto Cabeado, Bluetooth, Estrela, Barramento, Anel, Malha e Rede Tipo Árvore).
- `js/game.js`: Motor 3D, movimentação do personagem estilo Roblox, câmera orbital, simulação de pacotes (Ping) e testes de falha de cabos.

## Como Executar
Basta abrir o arquivo `index.html` diretamente em qualquer navegador moderno (Chrome, Edge, Firefox) com acesso à internet para carregar a biblioteca Three.js.
